# Phone-RF-Detector

RF Presence Detector is a web app that detects nearby devices using Wi-Fi and Bluetooth signals.

**Live Demo:** https://anuvrat03.github.io/Phone-RF-Detector/

## Features
- Detects Wi-Fi networks and BLE devices
- Shows signal strength and estimated distance
- Updates every 5 seconds

## Note
For full functionality on Android, use the native Android app version.
